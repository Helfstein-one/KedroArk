# test-glue-project

A Kedro project generated by **KedroArk**, tailored for deployment on **AWS Glue**.

## Getting Started

This project is configured with a complete Dev Container setup for local development.

1. Open this repository in VS Code.
2. Click "Reopen in Container" when prompted.
3. The container will automatically install Python 3.10, Java 11 (for PySpark), and all project dependencies.

## Running Tests

Tests are divided into multiple stages via Pytest markers:

```bash
# Fast unit tests
pytest -m unit

# Integration tests with I/O and mock data
pytest -m integration

# Full End-to-End Pipeline simulation
pytest -m e2e

# Performance benchmarks
pytest -m performance
```

## Infrastructure

Terraform files are available in `terraform/` configured for **AWS Glue**.

```bash
cd terraform
terraform init
terraform plan
```
